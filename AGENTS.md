## antislop
For UI, copy, people, mobile layout, or code comments work, read `~/.gemini/config/plugins/antislop/skills/antislop/SKILL.md` (core) and then the skill for the task:
- UI / visual: `~/.gemini/config/plugins/antislop/skills/antislop-ui/SKILL.md`
- Copy & text: `~/.gemini/config/plugins/antislop/skills/antislop-copywriting/SKILL.md`
- People: `~/.gemini/config/plugins/antislop/skills/antislop-human/SKILL.md`
- Mobile / responsive: `~/.gemini/config/plugins/antislop/skills/antislop-layoutmobile/SKILL.md`
- Code comments: `~/.gemini/config/plugins/antislop/skills/antislop-code/SKILL.md`
Before starting, ask the user when antislop applies: during the work, or after it is done.
